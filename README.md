# 📊 Food Delivery Delay & Cancellation Analysis

## 🔹 Problem Statement
This project analyzes food delivery operations to identify delay patterns, cancellation behavior, and revenue impact.

---

## 🔹 Tools Used
- Excel (Data preprocessing)
- SQL (Data analysis)

---

## 🔹 Key Analysis
- Compared actual delivery time with expected delivery time
- Identified late deliveries using delay flags
- Analyzed cancellation patterns and reasons
- Calculated revenue loss due to cancellations

---

## 🔹 Insights
- High traffic significantly increases delivery time
- Late deliveries are strongly linked to cancellations
- Certain customer zones show higher delivery delays
- Weather conditions negatively impact delivery performance
- Cancellations lead to revenue loss

---

## 🔹 Recommendations
- Optimize delivery routes in high-traffic areas
- Improve coordination with restaurants to reduce delays
- Monitor zones with consistently high delivery times

---

## 🔹 Project Files
- dataset.csv → Contains cleaned and modified dataset
- sql_queries.sql → Contains all SQL queries used for analysis
